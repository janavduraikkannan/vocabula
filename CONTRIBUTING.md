# Contributing to Vocābula

Thanks for wanting to help! Vocābula is a personal project run by one student, so please read this first.

**Issues and pull requests are welcome, but neither is guaranteed to be read, answered, merged or fixed.** The owner may close any issue or pull request without explanation.

By submitting a pull request, you confirm the work is yours to share. Before a pull request can be merged you must **sign the Contributor License Agreement (CLA)** through CLA Assistant: https://cla-assistant.io/janavduraikkannan/vocabula. Your contribution is then licensed under the same terms as the rest of Vocābula: code under the [GNU AGPL-3.0-or-later](LICENSE) and content (artwork, documentation, word lists, lesson text) under [CC BY-SA 4.0](LICENSE-CONTENT). **Never include an account key, an AI key, or personal details in an issue or pull request.** They are public.
